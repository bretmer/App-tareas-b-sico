# APLICACION DE GESTION DE TAREAS
Me permite poner en practica los conociminetos aprendidos para crear una aplicacion basica que me permite gestionar mis tareas diarias, donde me permitecrear, visualizar y eliminar tareas de manera dinámica. La aplicación cuenta con una interfaz limpia y minimalista donde los usuarios pueden agregar nuevas tareas mediante un campo de entrada y eliminarlas individualmente con un botón dedicado para cada tarea.
## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
## características de La aplicación basica de gestión de tareas
- Agregar nuevas tareas mediante un campo de texto
- Eliminar tareas individualmente
- Interfaz simple y centrada
- Interacción dinámica sin recargar la página
- Diseño responsivo
## Funcionamiento
- El usuario escribe una tarea en el campo de texto
- Al hacer click en "Agregar Tarea", se valida que el campo no esté vacío
- Se crea dinámicamente un elemento de lista con la tarea y un botón "Eliminar"
- La tarea se agrega a la lista visible
- El usuario puede eliminar tareas individuales haciendo click en su botón "Eliminar"
- El campo de texto se limpia automáticamente después de agregar cada tarea
